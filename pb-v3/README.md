# ПБ V3 — готовые файлы для размещения

В архиве последняя версия: новые символы коммерческих споров и судебного представительства, контрастный блок принципов и обновлённая форма на зелёном фоне.

## Структура

- `index.html` — главная страница, все тексты и форма.
- `css/styles.css` — базовые стили.
- `css/responsive.css` — мобильная версия.
- `css/v3.css` — дизайн V3 и последние правки.
- `js/main.js` — меню, диалоги, форма и подстановка примеров.
- `js/practice-examples.js` — тексты всех 10 примеров.
- `images/tree.png` — дерево на первом экране. Здесь можно хранить свои изображения.
- `legal/` — страницы документов компании.
- `tests/prefill.test.cjs` — проверка подстановки примеров.
- `TESTING.md` — чек-лист после размещения.

Никакой сборки, Node.js, npm и серверных ключей для размещения не требуется. Для просмотра откройте `index.html`. Отправку проверяйте с размещённого сайта по HTTPS.

## Как разместить

Содержимое видео по ссылке https://youtu.be/9oUoH_nF8S8 получить не удалось. Инструкция ниже универсальная, она не является пересказом ролика.

1. Распакуйте ZIP. Откройте папку `pb-v3`.
2. Если хостинг принимает папку — загрузите эту папку. Если он принимает файлы — загрузите её содержимое в папку сайта (часто она называется `public_html` или `www`).
3. Если в видео используется GitHub — создайте репозиторий и загрузите **содержимое** `pb-v3` в его корень. `index.html` должен лежать рядом с папками `css`, `js`, `images`.
4. Если сервис просит настройки: тип проекта — Static / Other; команда сборки — пустая; папка публикации — корень проекта (`.`). Для сервисов с собственными настройками выбирайте публикацию статических файлов.
5. Откройте полученную HTTPS-ссылку. Проверьте дерево, оформление, мобильное меню и форму.

Не загружайте только HTML: CSS, JS, изображения и legal тоже нужны. ZIP обычно нужно распаковать до загрузки, если сервис явно не поддерживает ZIP.

## Обращения на dansal08@mail.ru

В `index.html` уже задан адрес:

```html
<form action="https://formsubmit.co/dansal08@mail.ru"
      method="post"
      enctype="multipart/form-data">
```

Форма использует FormSubmit. Посетитель заполняет её, затем переходит на проверку сервиса. После проверки сервис обрабатывает отправку. Письмо содержит имя, контакт, направление, описание и вложение PDF/DOC/DOCX до 10 МБ. Если клиент указал email, он подставляется в Reply-To.

### Однократное включение после размещения

1. Откройте опубликованный сайт и отправьте тест: имя «Тест», свой контакт, сообщение «Проверка формы сайта».
2. Пройдите проверку FormSubmit.
3. Откройте **dansal08@mail.ru**, найдите письмо FormSubmit и подтвердите адрес. Проверьте также «Спам».
4. Вернитесь на сайт и отправьте **новую** тестовую заявку. Не полагайтесь на доставку первой заявки до активации.
5. Убедитесь, что новое письмо пришло; затем проверьте отправку с небольшим тестовым PDF без персональных данных.

Пароль от Mail.ru и API-ключ не нужны. Подтвердить адрес может только владелец почты. Реальная доставка в этом архиве не проверена: активация и проверка входящего письма ещё предстоят.

При смене домена повторите тест: сервис может запросить подтверждение для нового адреса сайта. Сообщение об успешной отправке выдаёт FormSubmit; сайт сам не подменяет его обещанием доставки.

### Обработка данных

Обращения и документы проходят через внешний сервис FormSubmit. В его документации указан срок хранения обращений 30 дней; файлы не входят в доступный через API архив. Перед приёмом реальных клиентских обращений заполните прежние шаблоны в `legal/` и согласуйте используемый сервис с компанией. Включённая по умолчанию reCAPTCHA сохранена.

Документация: https://formsubmit.co/ и https://formsubmit.co/documentation

## Что можно менять самостоятельно

Тексты — в HTML; цвета — в `css/v3.css`; примеры обращений — в `js/practice-examples.js`. Не меняйте `id`, `data-practice` и имена полей без соответствующей правки JS. Получатель заявок указан в `action` формы. Это не адрес посетителя и не обязательно публичный контакт компании.

В разделах с кейсами, отзывами, реквизитами и контактами сохранены прежние заглушки. Замените их своими утверждёнными материалами.

Это самостоятельный пакет для вашего хостинга. Текущая публикация Sites отдельно использует прежний серверный обработчик; отправка через FormSubmit подготовлена именно в этом ZIP.
